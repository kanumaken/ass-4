# Netflix Data Visualization Project

## Overview

This project analyzes Netflix shows and movies using Python and R to uncover insights about content genres and ratings. It includes data preparation, cleaning, exploration, and visualization tasks.

---

## Files Included

- `netflix.ipynb`: Main Python script for loading, cleaning, exploring, and visualizing Netflix data.
- `rvisual.r`: R script to recreate one visualization (Top Genres).
- `netflix_data.csv`: Original dataset.
- `README.md`: This file, explaining the project and how to run it.
